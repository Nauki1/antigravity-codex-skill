# 审查与收工规则

## 第1版：固定验收标准

开工前明确目标、可验证的验收标准、支持范围、不做事项和验收命令。未确认的假设不作为强制验收要求。

规划入口要求输出这些项目。审查入口默认读取目标工程的 `docs/task.md`，也接受显式 `--task`。显式文件缺失、为空或编码错误时停止；未提供文档时遵循用户明确指令与既有功能保证。

任务内容按 SHA-256 快照传入审查。审查期间任务文档变化，本次批准失效。审查不能自行扩大范围；可选命名调整、重构和未来功能不变成强制任务。相关安全、数据完整性和已有功能回归仍属审查范围。

快照通过 CLI 支持的 stdin 提示词传递，避免长文档超过 Windows 命令行长度限制。默认文档从缺失变为出现也会使本次批准失效；带 UTF-8 BOM 的空文档按空文件处理。
